# 🌍 TravelEase – AI Senior Travel Companion

## 🚀 Overview

TravelEase is an AI-powered travel assistant designed for senior citizens to plan safe, comfortable, and stress-free journeys.

It leverages Generative AI to provide personalized travel plans, safety recommendations, and easy step-by-step guidance.

---

## ✨ Key Features

* 🧠 AI-powered travel planning using Gemini API
* 👴 Senior-friendly recommendations (health, accessibility, comfort)
* 🛡 Safety-focused travel suggestions
* 🗺 Step-by-step itinerary generation
* 💬 Conversational AI interface

---

## 🛠 Tech Stack

* **Frontend:** React + TypeScript
* **AI:** Gemini API
* **Build Tool:** Vite
* **Architecture:** Modular component-based design

## ⚙️ Setup

```bash
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create `.env.local`:

```
VITE_GEMINI_API_KEY=your_api_key
```

---

## 🎯 Problem It Solves

Planning travel is complex for senior citizens due to:

* Health concerns
* Complex booking steps
* Safety risks

TravelEase simplifies this with AI-driven guidance.
